# Phase 6 — เทศกาลเมือง: รายงานผล

วันที่ 2026-10-14 · branch `claude/project-thread-3h4ruz` (ต่อจาก Phase 5 ใน PR เดียวกัน รวมงานแก้จาก QA บน emulator ของ Phase 5 แล้ว)

## ทำไมต้องมี

ก่อนหน้านี้แต่ละคนเล่นร้านของตัวเอง ไม่มีอะไรทำให้รู้สึกว่าอยู่ในเมืองเดียวกัน และทุกวันเหมือนกัน
เทศกาลเพิ่ม **จังหวะของสัปดาห์** (รอวันศุกร์) และ **เป้าหมายร่วมของทั้งเมือง** (ทุกคนช่วยกันขาย เมืองแต่งตัวสวยขึ้นตามความสำเร็จ)
และยังสอนเรื่องอุปสงค์: ช่วงเทศกาลคนอยากได้ของบางอย่างมากขึ้น ร้านที่เตรียมของถูกชนิดจะขายดี

## กติกา (ผมออกแบบเอง จากตัวเลือก "เทศกาลเมือง" ที่คุณเลือก)

| เรื่อง | กติกา |
|---|---|
| เวลา | ทุกสัปดาห์ ศุกร์ 00:00 ถึงอาทิตย์ 24:00 เวลาไทย จันทร์ถึงพฤหัสเห็นเป็น "กำลังจะเริ่ม" พร้อมนับถอยหลัง |
| งานหมุนเวียน 5 งาน | เทศกาลคลายร้อน (น้ำมะนาว/ชาไทย), งานขนมอบหอมกรุ่น (ขนมปัง/ชาไทย), เทศกาลดอกไม้บาน (ดอกไม้/น้ำมะนาว), ถนนคนเดินของกินเล่น (ลูกชิ้นปิ้ง/ขนมปัง), คืนโคมไฟ (ชาไทย/ดอกไม้) ทุกงานมีสินค้าที่ร้าน Lv.1 ขายได้ |
| ผลต่อลูกค้า NPC | สินค้าหลักคนอยากได้ x3 สินค้ารอง x2 คนเดินตลาดมากขึ้น x1.3 และมี "นักเที่ยวงาน" (ใส่หมวกปาร์ตี้ งบสูง) มาเฉพาะช่วงงาน |
| เป้าหมายเมือง | นับสินค้าเทศกาลที่ทุกร้านขายได้ แยกเมืองตามช่วงอายุ ขั้น 1 = 150 ชิ้น (โคมไฟ) ขั้น 2 = 500 (ไฟกะพริบ) ขั้น 3 = 1,200 (พลุเต็มฟ้า) ธงและซุ้มประตูขึ้นตั้งแต่เริ่มงาน |
| รางวัล | ทุกคนที่ช่วยขายอย่างน้อย 10 ชิ้นรับรางวัลทุกขั้นที่เมืองทำได้: 50 / 100 / 150 ทอง + XP และขั้น 3 ได้เฟอร์นิเจอร์ที่ระลึกของงาน (ซื้อไม่ได้) รับย้อนหลังได้ 1 สัปดาห์ |
| เมืองเปลี่ยนตาม | ช่วงงาน: ซุ้มประตูชื่องาน + ธงราวรอบเมือง · ขั้น 1: โคมไฟแกว่งบนเสา · ขั้น 2: ไฟกะพริบ · ขั้น 3: พลุยิงเป็นระยะ ตอนเมืองถึงขั้นใหม่ทุกคนในเมืองได้ยินพร้อมกันและเห็นพลุทันที |
| ความปลอดภัยเด็ก | เมืองแยกตามช่วงอายุ อันดับผู้ช่วยเห็นเฉพาะช่วงอายุเดียวกัน ไม่แสดงคนที่บล็อกกัน ผู้เล่นอายุต่ำกว่า 13 เห็นแค่อันดับกับแต้มของคนอื่น ไม่เห็นชื่อ ไม่มีรางวัลตามอันดับ (ไม่กดดันให้แข่ง) |

## เทสต์ตลาดที่เคยล้มบางครั้ง: เจอสาเหตุแล้ว

เทสต์ realtime ของ Phase 5 ที่เคยล้ม 1 ครั้งแล้วทำซ้ำไม่ได้ ล้มอีกครั้งในรอบนี้ สาเหตุคือ client แสดงเฉพาะลูกค้าของ "นาทีล่าสุด" และลูกค้าถูกกำหนดตายตัวต่อนาที ที่เลเวล 1 ราว 26% ของนาทีไม่มีลูกค้าเลย (วัดจาก 2,000 นาที) เทสต์ลองซ้ำ 20 ครั้งแต่ทั้งหมดอยู่ในนาทีจริงเดียวกัน จึงได้นาทีว่างเดิมทุกครั้ง
แก้ที่เทสต์ให้เลื่อนนาฬิกาของร้านไปทีละนาทีแทน (ตัวเกมไม่ผิด) รันซ้ำ 3 รอบเดี่ยว + ชุดเต็ม 3 รอบ ผ่านทั้งหมด
และตรึงปฏิทินเทศกาลในเทสต์ Phase 5 ไว้ที่วันพุธ ไม่อย่างนั้นถ้ารันเทสต์วันศุกร์ถึงอาทิตย์ผลจะเปลี่ยน

### บั๊กที่เจอบนเครื่องและแก้แล้ว

1. **ชื่อขั้นไม่ตรงกับของตกแต่งที่เห็น**: หน้าเทศกาลเขียนขั้น 1 "ประดับธง" ขั้น 2 "โคมไฟ" แต่ธงขึ้นตั้งแต่เริ่มงาน และขั้น 1 คือโคมไฟ ขั้น 2 คือไฟกะพริบ (ช้าไปหนึ่งขั้น) แก้ชื่อเป็น "แขวนโคมไฟทั้งเมือง" และ "ไฟกะพริบส่องสว่าง"
2. **เลเวลบน HUD ไม่อัปเดตหลังรับรางวัล** (server เลเวล 2 แต่ HUD ยัง Lv.1 จนเปิดแอปใหม่) เกิดกับรางวัลภารกิจด้วย แก้ให้คัดลอกเลเวลใหม่จากผลการรับรางวัลเข้า HUD

## ปัญหาที่ยังเหลือ / ยังไม่ได้ทดสอบ

- ยังไม่ได้ทดสอบบนมือถือจริง และยังไม่ได้ทดสอบเทศกาลอีก 4 งาน (ทดสอบแค่เทศกาลคลายร้อน)
- ชื่องานบนซุ้มประตูถูกปุ่มเทศกาลบน HUD บังเมื่อยืนที่จุดเกิด และพลุค่อนข้างเล็กจากมุมกล้องปัจจุบัน
- ร้านใหม่ทุกร้านชื่อ "My Lemonade Stand" เหมือนกัน แผงในตลาดจึงแยกกันยาก (ควรตั้งชื่อเริ่มต้นจากชื่อผู้เล่น)
- ถ้าร้านถูกคิดบัญชีตอนเจ้าของกดตั้งราคา/เติมของ แล้วการขายรอบนั้นทำให้เมืองถึงขั้นใหม่ สัญญาณ `festival:milestone` จะไม่ถูกส่ง (แต้มบันทึกครบ) client ดึงสถานะใหม่ทุก 60 วินาทีจึงยังเห็น แค่ไม่มีพลุทันที เป็นข้อจำกัดเดียวกับที่ทางนั้นไม่ส่ง `shop:updated` ใน Phase 5
- เป้า 150 / 500 / 1,200 ชิ้นเป็นตัวเลขตั้งต้น ถ้าผู้เล่นน้อยอาจยากเกิน ควรดูตัวเลขจริงหลังเปิดทดสอบ (แก้ที่ `FESTIVAL_TIERS`)
- เฟอร์นิเจอร์ที่ระลึก 5 ชิ้นยังใช้รูปทรงพื้นฐานเหมือนเฟอร์นิเจอร์อื่นในบ้าน ยังไม่มีโมเดลเฉพาะ
