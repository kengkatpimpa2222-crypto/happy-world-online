# Phase 8: ภาพ เสียง เพลง และมินิเกมทำของขาย

## ภาพรวม

ก่อนหน้านี้เมืองและตัวละครเป็นกล่องกับทรงกระบอก ไม่มีเสียงสักแอะ และทุกอย่างในเกมคือการกดเมนู เฟสนี้แก้ทั้งสองเรื่อง

1. **เมืองมีหน้าตาและมีเสียง** ตัวละครเป็นหุ่นน่ารักแบบ low-poly ที่เดินแกว่งแขนจริง บ้านเรือน ต้นไม้ พุ่มไม้ ธงหน้าประตู และเมฆที่ลอยช้า ๆ กลางวันมีเพลงสดใส ตกค่ำเพลงเปลี่ยนเป็นเพลงกล่อมนุ่ม ๆ ฝนตกในเกมก็ได้ยินเสียงฝน ขายของได้มีเหรียญเด้งพร้อมเสียงกริ๊ง
2. **ทำของขายเองด้วยมือ** ในหน้าร้านมีปุ่ม "ทำเอง" ใต้สินค้าแต่ละชนิด กดแล้วเข้ามินิเกมสั้น ๆ 40–60 วินาที เล่นดีได้ดาว ได้ดาวมากได้ของเข้าคลังฟรีมาก ของที่ทำเองต้นทุน 0 จึงดึงต้นทุนเฉลี่ยของร้านลง กำไรต่อชิ้นสูงขึ้น ผูกกับลูปเดิมของเกมโดยตรง

## มินิเกม 3 เกม (ผมออกแบบเอง)

| เกม | ใช้ทำ | วิธีเล่น | เวลา |
|---|---|---|---|
| เก็บมะนาว / เก็บดอกไม้ | น้ำมะนาว, ดอกไม้ | ลากตะกร้ารับของดีที่ตกลงมา หลบใบไม้แห้งกับก้อนกรวด รับต่อเนื่องได้คอมโบ | 45 วิ |
| ปิ้งลูกชิ้น / อบขนมปัง | ลูกชิ้น, ขนมปัง | แตะเตาว่างเพื่อวางของ 4 เตา รอให้สุกแล้วแตะเก็บตอนเข็มอยู่ในโซนพอดี เก็บพอดีติดกันได้โบนัส ทิ้งไว้นานไหม้ | 60 วิ |
| ชงชาไทย | ชาไทย | กดค้างเพื่อเท ยิ่งกดนานยิ่งไหลแรง ปล่อยให้ระดับอยู่ในแถบเป้าหมาย ล้นแก้วเสียแก้วนั้น แถบแคบลงเรื่อย ๆ | 40 วิ |

- ได้ดาว 1/2/3 = ของ 4/7/10 ชิ้น (0 ดาว = 1 ชิ้นปลอบใจ) + XP 1/3/5/8
- วันละ 15 รอบที่ได้ของ (นับตามวันเวลาไทย เที่ยงคืนรีเซ็ต) เกินนั้นเล่นเพื่อสนุกและทำสถิติได้
- เควสใหม่ "ทำของขายเอง 3 รอบ" (100 ทอง, 40 XP)
- เหมาะกับเด็ก: ไม่มีความรุนแรง ไม่มีการแข่งกับคนแปลกหน้า ไม่มีโฆษณาหรือการจ่ายเงินในมินิเกม

**กันโกง** server เป็นคนตัดสินทั้งหมด: server สุ่ม seed ของรอบ (ด่านเหมือนกันทุกเครื่องจาก seed เดียวกัน), ปฏิเสธคะแนนที่ส่งมาก่อนรอบจะจบได้, ปฏิเสธคะแนนเกินเพดานที่เล่นได้จริง, รอบที่ค้างเกิน 10 นาทีเป็นโมฆะ, ส่งจบซ้ำได้ผลเดิมไม่ได้ของซ้ำ และล็อกแถวผู้เล่นตอนจบรอบกันการยิงพร้อมกันเพื่อเกินโควตา

**ความยากจูนจากบอท** เทสต์ C# ให้บอท 3 ระดับ (เล่นมั่ว, เล่นพอใช้, เล่นเก่ง) เล่นด่านจริงหลาย seed แล้วตรวจว่าบอทมั่วได้ 0–1 ดาว บอทพอใช้ได้ 1–2 ดาว บอทเก่งได้ 3 ดาวเกือบทุกรอบ เกณฑ์ดาวเลยไม่ได้มาจากการเดา

## ที่มาของภาพและเสียง (ใช้เชิงพาณิชย์ได้ทั้งหมด)

- **โมเดล 3D และเสียงเอฟเฟกต์บางส่วน**: Kenney (CC0, public domain) จาก Starter Kit ทางการบน GitHub ของ Kenney
- **เพลง 3 เพลง เสียงฝน แตรฉลอง เสียงดาว เสียงนับถอยหลัง เสียงปิ้ง เสียงเท**: แต่งและสังเคราะห์ขึ้นใหม่จากโค้ด (`apps/game-client/Tools/audio/compose.py`) ไม่มีการใช้ sample ของใคร เพลงวนต่อกันไม่มีรอยสะดุด
- **ภาพในมินิเกม 21 ชิ้น** (มะนาว น้ำแข็ง ใบสะระแหน่ ดอกไม้ ไม้เสียบ ขนมปัง แก้ว ดาว ฯลฯ): วาดจากโค้ด (`apps/game-client/Tools/art/draw_sprites.py`)
- รายการไฟล์ทีละไฟล์พร้อมแหล่งที่มา: [apps/game-client/ART_CREDITS.md](../apps/game-client/ART_CREDITS.md)

ขนาดที่เพิ่มใน APK โดยประมาณ: เสียง 1.8 MB, โมเดล 0.6 MB, ภาพมินิเกม 0.4 MB

## ไฟล์ที่สร้างหรือแก้

**Client (Unity)**
- ใหม่: `Core/Art/GlbModel.cs` ตัวอ่าน .glb (แปลงแกนพิกัด glTF → Unity, อ่านแอนิเมชัน idle/walk ของตัวละคร), `Unity/Art/ModelLibrary.cs`, `Unity/Art/CharacterRig.cs`, `Unity/Audio/GameAudio.cs` (เพลงตามเวลา/อากาศ, crossfade, ปรับเสียงเพลง/เอฟเฟกต์แยกกันในหน้าโปรไฟล์), `Core/Minigames/*` (กติกาและลอจิก 3 เกม), `Unity/Minigames/MinigameScreen.cs`, `Editor/ArtImportSettings.cs`
- แก้: `AvatarView` (ใช้ตัวละครโมเดล), `MarketView` (NPC เป็นโมเดล + เหรียญเด้ง), `CityBuilder` (บ้าน ต้นไม้ พุ่ม ธง เมฆ พื้นมีลาย), `UiKit` + `GameScreens` (ปุ่มมุมมน เงา เด้งตอนกด เสียงคลิก ปุ่ม "ทำเอง", ตั้งค่าเสียง), `GameSession` (เปิดระบบเสียง)
- ทุกจุดที่ใช้โมเดล ถ้าโหลดไม่ได้จะกลับไปวาด primitive แบบเดิม เกมไม่พัง
- ไฟล์ `.meta` ของไฟล์ใหม่สร้างไว้แล้วแบบขั้นต่ำ (มีแค่ guid) Unity จะเติมค่าที่เหลือตอนเปิดโปรเจกต์ ให้ commit `.meta` ที่ Unity แก้ตามไปด้วย

**Backend**
- `packages/shared-contracts/src/minigame.ts` (กติกาเดียวกับฝั่ง C#), schemas, error codes 3 ตัว
- `apps/backend/src/business/minigame.service.ts`, `minigame.controller.ts`: `GET /minigames`, `POST /minigames/start`, `POST /minigames/:id/finish`
- migration `20261016090000_minigames` (ตาราง `minigame_sessions` เพิ่มอย่างเดียว ไม่แตะตารางเดิม), seed เควสใหม่
- เทสต์: `apps/backend/test/minigame.e2e-spec.ts`, `Tests/HappyWorld.Core.Tests/ArtTests.cs`, `MinigameTests.cs`
- เอกสาร: `docs/api.md`, `docs/database.md`, `docs/unity-client.md`

## ยังไม่ได้ตรวจ (ต้องทำบนเครื่องที่มี Unity)

- **ยังไม่ได้เปิดใน Unity Editor และยังไม่ได้ build APK** ในเครื่อง cloud ไม่มี Unity จึงยังไม่เห็นภาพจริง ไม่ได้ยินเสียงจริง และ `Editor/ArtImportSettings.cs` ยังไม่ได้ compile (ต้องใช้ UnityEditor)
- สิ่งที่ควรดูตอน QA: ขนาดและทิศของตัวละคร/บ้านเทียบกับแผนที่, แสงบนโมเดล (shader Legacy Diffuse), ความลื่นของมินิเกมบนมือถือจริง (เฟรมเรต, ลากตะกร้าด้วยนิ้ว), ระดับเสียงเพลงกับเอฟเฟกต์
- ถ้ามีหน้าต่างอื่นเด้งขึ้นมาระหว่างเล่นมินิเกม (เช่นรายงานร้านตอนกลับเข้าเกม) หน้ามินิเกมจะถูกปิดและรอบนั้นจะไม่ได้ของ (รอบหมดอายุเองใน 10 นาที) ยังไม่ได้ทำระบบกันกรณีนี้
- `docs/openapi.json` ยังไม่ได้ generate ใหม่ (ค้างมาตั้งแต่ Phase 6)
