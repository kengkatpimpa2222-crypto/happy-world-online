# Phase 9: ออกสำรวจ วัตถุดิบ และงานฝีมือ

## ภาพรวม

ก่อนหน้านี้ร้านมีของขายได้ 2 ทาง: จ่ายทองซื้อจากระบบ หรือเล่นมินิเกมทำเอง (Phase 8) ยังไม่มี "การผจญภัย" ที่ป้อนของเข้าเศรษฐกิจ ทั้งที่ทั้งแผน Cozy MMORPG และ GDD Virtual World บอกว่าระบบต้องเชื่อมกัน เฟสนี้ต่อสายนั้น

**ออกสำรวจ → ได้วัตถุดิบ → คราฟต์เป็นสินค้าพิเศษ → วางแผงขาย → ได้ทอง → (ต่อไป) แต่งบ้าน**

ตรงกับ GDD ข้อ 2 เขต E Countryside และสายชีวิต "นักสำรวจ" กับ "ช่างและผู้ผลิต" ในข้อ 3

### การออกสำรวจ (RPG แบบไม่รุนแรง)

- 3 สถานที่: สวนผลไม้ริมคลอง (3 นาที), ป่าดอกไม้ (6 นาที, นักสำรวจ Lv.2), หุบเขาสมุนไพร (10 นาที, นักสำรวจ Lv.4)
- เลือกแผนก่อนออกเดินทาง: **ระวัง** (ผ่านง่าย ไม่เสียของ เก็บได้น้อย), **ปกติ**, **บุก** (เก็บได้เยอะ แต่พลาดแล้วของหล่นหาย)
- ระหว่างทางเจอเหตุการณ์ 2-3 อย่างจาก 10 แบบ เช่น ฝูงลิงขโมยมะม่วง ลูกหมาหลงทาง ผึ้งป่าหวงรัง ควายป่าขวางสะพาน คุณตาหมอยา ผ่านได้หรือพลาดขึ้นกับเลเวลนักสำรวจและแผนที่เลือก
- ทริปเดินต่อตอนปิดเกม กลับมากด "ดูผล" แล้วได้อ่านเรื่องเล่าภาษาไทยว่าเกิดอะไรขึ้นบ้าง
- ไปได้ทีละทริป ไม่มีพลังงานหรือโควตารายวัน เวลาเดินทางคือตัวจำกัด จึงไม่มีอะไรให้กลัวพลาดถ้าไม่ได้เข้าเกม

ค่าเฉลี่ยจากการจำลอง 4,000 seed (เลเวล 1): สวนผลไม้ได้ของ 6.9 / 7.3 / 8.8 ชิ้น ตามแผนระวัง / ปกติ / บุก ส่วนหุบเขาสมุนไพรได้ 11.7 / 13.2 / 13.8 ชิ้น แผนบุกเสี่ยงที่สุดตอนเลเวลต่ำ และคุ้มขึ้นเมื่อเลเวลสูง (หุบเขาที่ Lv.4 ได้ 12.7 / 14.5 / 16.2 ชิ้น)

### งานฝีมือ

| สินค้า | วัตถุดิบ | ได้ | ค่าแรง | ช่าง Lv. | ราคาตลาด |
|---|---|---|---|---|---|
| ข้าวเหนียวมะม่วง | มะม่วง + ข้าวเหนียว + มะพร้าว | 3 กล่อง | 6 ทอง | 1 | 35 |
| พวงมาลัยมะลิ | มะลิ 3 + ดาวเรือง | 2 พวง | 4 ทอง | 1 | 28 |
| ยาหม่องสมุนไพร | สมุนไพร 2 + ตะไคร้ + ขี้ผึ้ง | 2 ตลับ | 8 ทอง | 2 | 45 |
| แยมมะม่วงน้ำผึ้ง | มะม่วง 2 + น้ำผึ้งป่า | 2 ขวด | 6 ทอง | 2 | 55 |

- ของพวกนี้ **ซื้อด้วยทองไม่ได้** และไม่มีมินิเกม ต้องออกสำรวจเท่านั้น และขายได้ราคาสูงกว่าน้ำมะนาว (10) หรือลูกชิ้น (20) ผู้เล่นจึงมีเหตุผลออกไปสำรวจ
- ค่าแรงเป็นตัวดูดทองออกจากระบบ (GDD ข้อ 4 เรื่องเงินเฟ้อ) และลงเป็นรายจ่ายของร้าน ต้นทุนต่อชิ้นที่ร้านแสดง = ค่าแรง ÷ จำนวนชิ้น
- ช่างเลเวล 4, 7, 10 ได้เพิ่มครั้งละ 1 ชิ้น
- ลูกค้า NPC ไม่ถามหาสินค้างานฝีมือจากร้านที่ไม่มีขาย ผู้เล่นที่ยังไม่ได้ออกสำรวจจึงไม่เสียลูกค้า

### กันโกงและกันของซ้ำ

- server สุ่ม seed ตอนออกเดินทางและ **ไม่เคยส่งให้เครื่อง** ผลคำนวณตอนกด "ดูผล" จาก (seed, สถานที่, แผน, เลเวลตอนออก) ผู้เล่นจึงดูผลล่วงหน้าหรือสุ่มใหม่ไม่ได้
- กด "ดูผล" ซ้ำหรือพร้อมกันได้เรื่องเดิม ได้ของครั้งเดียว
- **ledger ของไอเทม** (`inventory_transactions`) ใหม่: ทุกการเพิ่มหรือใช้วัตถุดิบมีแถวบันทึกพร้อม idempotency key ลบหรือแก้แถวไม่ได้ (trigger) เหมือน ledger เงิน การใช้วัตถุดิบเป็น UPDATE แบบมีเงื่อนไข คราฟต์พร้อมกัน 5 คำขอจากวัตถุดิบ 3 ชุดจึงสำเร็จแค่ 3 (มี test)
- คราฟต์ต้องส่ง `Idempotency-Key` กดซ้ำไม่เสียค่าแรงซ้ำ วัตถุดิบไม่พอแล้วค่าแรงถูกยกเลิกไปพร้อมกัน

## Phase 9.1: ปรับ UX การสำรวจ และตรวจสอบ Phase 9 ให้ครบ (15 ต.ค. 2026)

### ตรวจก่อนแก้: อะไรถูกอยู่แล้ว (ไม่ได้แก้)

- server ตัดสินว่าทริปจบหรือยัง: claim ก่อนเวลาได้ `409 EXPEDITION_NOT_FINISHED` พร้อม `secondsLeft`
- claim ล็อกแถวทริป (`FOR UPDATE`) เก็บผลไว้ใน `expeditions.result` เรียกซ้ำหรือพร้อมกันได้ผลเดิม (`replayed: true`) และของเข้าครั้งเดียวผ่าน ledger key `expedition:<id>:<material>`
- เริ่มทริปล็อกโปรไฟล์ + partial unique index กันมี 2 ทริปพร้อมกัน, `GET /expeditions` อ่านอย่างเดียว ไม่เคยสร้างทริป
- คราฟต์: ค่าแรง วัตถุดิบ และสต็อกอยู่ใน transaction เดียว, `Idempotency-Key` กันหักซ้ำ, UPDATE แบบมีเงื่อนไขกันใช้วัตถุดิบเกิน
- XP ของนักสำรวจ/ช่างฝีมือเก็บใน `player_skills` บน server

### ปัญหาที่พบและสิ่งที่แก้

| ปัญหา | แก้อย่างไร |
|---|---|
| หน้า "กำลังเดินทาง" นับถอยหลังนิ่ง ต้องกด "รีเฟรช" | `Core/World/ExpeditionTracker.cs` (ใหม่) นับถอยหลังจาก `secondsLeft` ของ server บนนาฬิกาของแอป (`Time.realtimeSinceStartupAsDouble` ไม่ใช่เวลาในเครื่องที่ผู้เล่นแก้ได้) หน้าจอและปุ่ม "ออกสำรวจ" บน HUD อัปเดตเอง 4 ครั้ง/วินาที |
| นับถึง 0 แล้ว client ไม่รู้ว่าเสร็จจริงไหม | พอถึง 0 ถาม `GET /expeditions` หนึ่งครั้ง ถ้า server บอกยังไม่ถึงก็เชื่อ server และเว้นอย่างน้อย 3 วินาทีก่อนถามใหม่ ปุ่ม "ดูผล" เปิดเฉพาะเมื่อ server บอก `ready` |
| ปิดแอป/กลับจาก background/reconnect แล้วเวลาเพี้ยน | ซิงก์ใหม่ตอนเข้าเมือง, `OnApplicationPause(false)`, `OnApplicationFocus(true)`, realtime `ready` และตอนเปิดหน้าสำรวจ |
| ไม่มีอะไรบอกเมื่อทริปกลับ | toast "กลับจาก...แล้ว" พร้อมปุ่ม "ดูผล" (แสดงครั้งเดียวต่อทริป รวมทริปที่กลับระหว่างปิดแอป) HUD แสดง "ออกสำรวจ 2:05" / "ถึงแล้ว!" |
| เน็ตหลุด, timeout, server error | ไม่ toast ซ้ำทุกรอบ แสดงสถานะ "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ จะลองใหม่ใน N วินาที" และลองใหม่แบบ 5, 10, 20, 40, 60, 60... วินาที มีปุ่ม "ลองใหม่" |
| กด "ดูผล", "ไปเลย", "ทำ 1" รัวได้ (server กันของซ้ำแล้ว แต่ครั้งที่สองขึ้น "ทำได้ 0 กล่อง") | ปิดปุ่มระหว่างรอคำตอบ, claim ผ่าน `TryBeginClaim` ทีละครั้ง, คราฟต์ที่ได้ `replayed` แสดงว่า "ทำไปแล้ว ไม่ได้หักซ้ำ" key เดิมใช้ต่อเมื่อ retry หลัง timeout |
| ผู้เล่นใหม่ 1 ใน 5 กลับจากทริปแรกแล้วยังคราฟต์ไม่ได้ (ดูด้านล่าง) | ตาข่ายทริปแรก (first-visit safety net) |

การ polling: ไม่มีทริป = ไม่ถามเลย, ระหว่างทาง = ไม่ถาม, ถึงเวลา = 1 ครั้ง QA จริง 19 ทริปใช้ `GET /expeditions` รวม 22 ครั้ง (รวมการเปิดหน้าจอและ relogin)

### บาลานซ์: ตาข่ายทริปแรก

**ค่าเดิมไม่เปลี่ยน** (drop rate, จำนวน roll, เหตุการณ์, ราคา, ค่าแรง เหมือนเดิมทุกตัว) เพิ่มกติกาเดียว: ทริปแรกที่ claim ของแต่ละสถานที่ ได้วัตถุดิบครบสำหรับสูตรหลักของที่นั้นอย่างน้อย 1 ชุด เติมเฉพาะที่ขาดให้ถึง 1 ชุดพอดี ไม่บวกเพิ่ม ไม่ดึงเลขสุ่มเพิ่ม (เรื่องราวและเหตุการณ์เหมือนเดิมทุกอย่าง) ทริปต่อไปไม่มีอีก และผู้เล่นที่เคยไปแล้วไม่ได้ย้อนหลัง

| สถานที่ | สูตรที่รับประกัน 1 ชุด |
|---|---|
| สวนผลไม้ริมคลอง | ข้าวเหนียวมะม่วง (มะม่วง + ข้าวเหนียว + มะพร้าว) |
| ป่าดอกไม้ | พวงมาลัยมะลิ (มะลิ 3 + ดาวเรือง) |
