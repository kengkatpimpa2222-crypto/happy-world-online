# Phase 13: ศึกลูกโป่งน้ำ (Splash Arena) และระบบแรงค์

Base branch: `claude/project-thread-ncua1d` (PR #7 Phase 12 ซึ่งต่อจาก PR #6, #5, #4 ยังไม่ merge ทั้งหมด)
คำขอ: "ลงแรงค์กับโจมตีอีกทีมในเกมด้วยนะ"

## ไอเดียหลัก: สู้กันได้ แต่เมืองยังปลอดภัย

Happy World Online เป็นเกมโลกออนไลน์สำหรับทุกวัย การเปิดให้ "โจมตีกันได้ทุกที่" จะทำให้คนที่มาแต่งบ้านหรือเปิดร้านโดนรังแก เฟสนี้จึงทำการต่อสู้เป็น **โหมดสมัครใจ** ที่มีกติกาชัดเจน:

- **ศึกลูกโป่งน้ำ**: ทีมแดงปะทะทีมฟ้า 3 ต่อ 3 รอบละ 2 นาที อาวุธคือลูกโป่งน้ำ (ไม่มีเลือด ไม่มีใครตาย แค่ "เปียกโชก") โดน 4 ลูกต้องกลับไปตากตัวที่ฐาน 3 วินาที ทีมที่ทำให้อีกฝั่งเปียกได้มากกว่าชนะ
- **เข้าได้จากคิวเท่านั้น** ในเมือง บ้าน ตลาด ไม่มีใครปาใส่ใครได้ server ปฏิเสธ `arena:throw` ทุกครั้งที่ไม่ได้อยู่ในแมตช์
- **เล่นได้แม้คนยังน้อย**: รอคิวเกิน 15 วินาที บอทใจดี (น้องเป็ดน้ำ น้องปลาทอง ...) มาเติมทีม บอทช้ากว่าคนและปาพลาดได้ ผู้เล่นใหม่จึงชนะได้ แมตช์ที่มีบอทขยับแต้มแรงค์แค่ครึ่งเดียว
- **ยุติธรรม**: server ตัดสินทุกอย่าง (ตำแหน่ง ความเร็ว ระยะปา คูลดาวน์ การโดน) ทุกคนค่าพลังเท่ากัน ไม่มีอะไรที่ซื้อด้วยเงินแล้วเก่งขึ้น (สอดคล้องเป้าหมาย "ไม่บังคับจ่ายเพื่อสนุก")
- **กันรังแก**: จับคู่เฉพาะช่วงอายุเดียวกัน (UNDER_13 / TEEN / ADULT ไม่เจอกัน) คนที่บล็อกกันไม่อยู่แมตช์เดียวกัน ไม่มีแชทพิมพ์อิสระในอารีน่า และเกิดใหม่แล้วโดนไม่ได้ 1.5 วินาที (กันยืนดักที่ฐาน)
- **ทีมเวิร์ก** (เป้าหมายข้อ 3): คะแนนเป็นของทีม ไม่ใช่ของคนเดียว ทีมแบ่งตามแต้มแบบ snake draft (คนเก่งสุดกับคนอ่อนสุดอยู่ทีมเดียวกัน) แต่ละแมตช์จึงสูสี

## แรงค์

| ระดับ | แต้ม |
|---|---|
| บรอนซ์ | 0–1099 (เริ่ม 1000) |
| ซิลเวอร์ | 1100+ |
| โกลด์ | 1250+ |
| แพลทินัม | 1400+ |
| ไดมอนด์ | 1550+ |
| ดาวเด่น | 1700+ |

- คิดแต้มแบบ Elo ของทีม (K = 32): ชนะทีมที่แข็งกว่าได้แต้มมาก ชนะเสมอได้อย่างน้อย +1
- **ซีซั่นรายเดือน** ตามเวลาไทย ซีซั่นใหม่เก็บแต้มไว้ครึ่งหนึ่ง (1600 → 1300) คนเก่งยังอยู่ข้างบน แต่ทุกคนมีลุ้นใหม่ทุกเดือน
- กระดานอันดับแยกตามช่วงอายุ แสดงแค่ชื่อในเกม
- เหรียญรางวัล: ชนะ 20 เสมอ 12 แพ้ 6 ทอง วันละ 10 แมตช์แรก (ไม่บังคับเข้าทุกวัน ข้ามวันไม่เสียอะไร) ผ่าน wallet ledger `ARENA_REWARD` จ่ายครั้งเดียวต่อแมตช์

## ยังไม่ได้ตรวจ / ข้อจำกัดที่รู้

- **ยังไม่ได้เปิดใน Unity 6 Editor และยังไม่ได้ build APK** ชั้น Unity ผ่านแค่ type-check กับ reference assemblies ต้องทดสอบจริงบนเครื่องที่มี Unity (หน้าตาสนาม ปุ่ม ลูกโป่ง กล้อง)
- ไฟล์ `.meta` ใหม่ 2 ไฟล์มีแค่ guid Unity จะเติมเอง
- คิวและแมตช์อยู่ในหน่วยความจำของ backend instance ที่ผู้เล่นต่ออยู่ ถ้ารันหลาย instance ผู้เล่นจะเจอกันเฉพาะใน instance เดียวกัน (ทางแก้ในอนาคต: matchmaker กลางบน Redis หรือ sticky routing ตามแมตช์) ถ้า server รีสตาร์ทกลางแมตช์ แมตช์นั้นหายไม่ถูกบันทึก
- หลุดเน็ตกลางแมตช์ = ออกทันที (นับแพ้) ยังไม่มีการต่อกลับเข้าแมตช์เดิม
- ตัวละครยังเป็นโมเดล Kenney ของ branch นี้ ท่าปาเป็นการหันหน้าเฉย ๆ (avatar อนิเมะอยู่ใน PR #8 คนละสาย ถ้า merge แล้วเพิ่มท่าปาได้)
- ยังไม่มีรางวัลตกแต่งตอนจบซีซั่น (เช่นกรอบชื่อตามระดับ) ไว้ทำคู่กับร้านไอเทมตกแต่ง
- ยังไม่มีปุ่ม "ชวนเพื่อนเข้าทีมเดียวกัน" (ปาร์ตี้) ตอนนี้จับคู่แบบสุ่มเท่านั้น
