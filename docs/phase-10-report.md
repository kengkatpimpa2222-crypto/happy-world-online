# Phase 10: บ้านหลังแรกและย่านที่อยู่อาศัย

Base branch: `claude/project-thread-0yx7ct` (PR #4 Phase 9 ยังเปิดอยู่ ยังไม่ merge) แผนก่อนลงมือ: [phase-10-plan.md](phase-10-plan.md)

## ภาพรวม

Phase 9 ทำให้ผู้เล่นหาเงินได้หลายทาง แต่ยังไม่มีที่ไหนให้ "ใช้ชีวิต" GDD Virtual World ข้อ 2 (เขต B Residential) และข้อ 5 (Housing) บอกว่าบ้านคือหัวใจของการอยู่ในเมือง เฟสนี้ให้ทุกคนมีบ้านจริงบนถนนเดียวกันกับเพื่อน

**เดินเข้าย่านบ้าน → รับบ้านหลังแรก → เข้าบ้าน → จัดเฟอร์นิเจอร์ → บันทึก → ชวนเพื่อนมาเยี่ยม**

### สิ่งที่ผู้เล่นเห็น

- **ย่านบ้าน** ในโซน HOMES (ประตูจากลานกลางเดิม) ถนนหนึ่งเส้น ทางเท้าสองฝั่ง บ้าน 12 หลังต่อถนน หันหน้าเข้าถนน ป้ายเหนือบ้านบอกชื่อเจ้าของ (บ้านเพื่อนมี ♥, บ้านตัวเองสีส้ม) ที่ว่างมีรั้วเตี้ยกับป้าย "ที่ว่าง" พรมหน้าบ้านเป็นสีเขียวเมื่อเราเข้าได้
- **รับบ้าน** จากปุ่ม "บ้าน" บน HUD ได้ที่ดินแปลงว่างแรกในย่าน (ต่อถนนใหม่อัตโนมัติเมื่อเต็ม) และของขวัญขึ้นบ้านใหม่: เตียงเดี่ยว โต๊ะไม้ กระถางต้นไม้ 2 ใบ (รวมเก้าอี้ที่ได้ตั้งแต่สมัคร)
- **เข้า/ออกบ้าน**: ยืนบนพรมแล้วกด E หรือแตะปุ่มที่ขึ้นมา หรือกด "กลับบ้าน" จากหน้าบ้านได้ทุกที่ ในบ้านเดินไปที่ประตูหรือกด "ออกจากบ้าน"
- **จัดบ้าน**: กล้องเปลี่ยนเป็นมุมมองจากด้านบน แถบล่างแสดงของในกระเป๋า แตะเพื่อหยิบ เงาเขียว = วางได้ เงาแดง = ชนของอื่นหรือล้นห้อง หมุน ย้าย เก็บเข้ากระเป๋า แล้วกด "บันทึก" หรือ "ยกเลิก" (ยกเลิกแล้วห้องกลับเป็นเหมือนเดิม ไม่มีอะไรส่งไป server)
- **เยี่ยมบ้าน**: ตั้งได้ 3 แบบ ส่วนตัว / เฉพาะเพื่อน (ค่าเริ่มต้น) / ทุกคน หน้าบ้านมีรายชื่อบ้านเพื่อนพร้อมปุ่ม "ไปเยี่ยม" กดชื่อผู้เล่นในเมืองหรือในหน้าเพื่อนก็มีปุ่ม "ไปเยี่ยมบ้าน" คนในบ้านเห็นกันและกัน และเห็นเฟอร์นิเจอร์ขยับทันทีเมื่อเจ้าของบันทึก
- ถ้าเจ้าของเปลี่ยนเป็นส่วนตัว เลิกเป็นเพื่อน หรือบล็อก ผู้มาเยี่ยมถูกพาออกจากบ้านทันทีพร้อมข้อความ

### ความปลอดภัยของทรัพย์สิน

- **ใช้ระบบเดิม ไม่สร้างใหม่**: ตาราง `player_homes`/`home_furniture` มีตั้งแต่ migration แรก, ไอเทมอยู่ใน `player_inventory`, การเปลี่ยนจำนวนผ่าน `InventoryService` และ ledger `inventory_transactions` ของ Phase 9
- เฟอร์นิเจอร์ที่ "มี" = ในกระเป๋า + ที่วางอยู่ในบ้าน วางของลดในกระเป๋า (`HOME_PLACE`) เก็บของคืนกระเป๋า (`HOME_REMOVE`) ใน transaction เดียวกับผังบ้าน ผลรวมจึงคงที่เสมอ (มี test)
- server ตรวจทุกอย่างเอง: เจ้าของบ้าน, ของเป็นของเราจริงและเป็นเฟอร์นิเจอร์, อยู่ในห้อง, ไม่ทับกัน, มุมหมุนถูก, ไม่เกิน 40 ชิ้น ข้อมูลที่ client ส่งมีแค่ตำแหน่ง ไม่มีราคาหรือจำนวน
- **รับบ้านครั้งเดียว**: advisory lock ต่อช่วงอายุ + unique index ที่ดิน + `claimed_at` กด 5 ครั้งพร้อมกันได้บ้านหลังเดียว ของขวัญชุดเดียว (ledger key `home-claim:<itemId>`)
- **แก้พร้อมกัน**: ล็อกแถวบ้าน `FOR UPDATE` + `layout_version` (optimistic) PC กับมือถือแก้พร้อมกัน เครื่องที่บันทึกทีหลังได้ `HOME_LAYOUT_CONFLICT` แล้วโหลดใหม่ ไม่มีของหายหรืองอก
- **กดซ้ำ/เน็ตหลุด**: `Idempotency-Key` เก็บไว้ที่บ้าน (`layout_save_key`) ส่งซ้ำได้ผลเดิม ใช้ key เดิมกับผังอื่น = `IDEMPOTENCY_KEY_REUSED`
- **คนนอกแก้ไม่ได้**: ทุก endpoint ที่เขียนเป็น `/homes/me/*` ไม่มีทางระบุบ้านคนอื่น ผู้มาเยี่ยมทำได้แค่ดูและเดิน
- **ความปลอดภัยเด็ก**: ย่านบ้านแยกตามช่วงอายุ บ้านต่างช่วงอายุหรือคนที่บล็อกกันตอบ 404 (ไม่บอกว่ามีบ้าน) เจ้าของที่บล็อกกันแสดงเป็นบ้านไม่มีชื่อ
- จำกัดความถี่ (เขียน 30/นาที, เยี่ยม 60/นาที) และ audit log ทุกการรับบ้าน บันทึกผัง และเปลี่ยนสิทธิ์

### ข้ามแพลตฟอร์ม

บัญชีเดียวกัน ข้อมูลเดียวกันบน server ทั้ง PC และมือถือ ห้องบ้าน `home:<ownerId>` ส่ง event เฉพาะคนในบ้าน (ไม่ broadcast ทั้งเมือง) เน็ตหลุดแล้วต่อใหม่ client กลับเข้าบ้านเดิมเอง (`RejoinAsync`) ตอนจัดบ้านเน็ตหลุดยังจัดต่อได้ กดบันทึกตอนกลับมาออนไลน์ด้วย key เดิม

- ผังอยู่ครบหลัง logout/login
- สิทธิ์เยี่ยม: เฉพาะเพื่อน/ส่วนตัว/ทุกคน, ต่างช่วงอายุ, บล็อก, ยังไม่รับบ้าน, คนอื่นแก้หรือเอาของไปไม่ได้
- realtime: เข้าบ้าน, เห็นผังเปลี่ยน, เดินชนผนัง, คนแปลกหน้าเข้าไม่ได้, ถูกพาออกเมื่อเปลี่ยนเป็นส่วนตัว/เลิกเพื่อน/บล็อก

C# ใหม่ 13 ข้อ: อ่าน JSON จาก server จริง, editor (วาง หมุนชิดผนัง ย้ายแล้ว id เดิม ยกเลิก เก็บเข้ากระเป๋า เงาแดง), คำนวณตาราง↔พิกัดโลก, ข้อความหน้าประตู, CityState ในบ้าน, กติกาตรงกับ server และ integration กับ backend จริง (รับบ้าน → จัด → บันทึก + ส่งซ้ำ → conflict → logout/login แล้วผังเดิม → คนแปลกหน้าถูกปฏิเสธ → เป็นเพื่อนแล้วเยี่ยมได้ → realtime เข้าบ้านและถูกพาออก)

## ข้อจำกัดที่รู้อยู่

- เฟอร์นิเจอร์ในบ้านวาดด้วยรูปทรงพื้นฐาน (กล่อง ทรงกระบอก) ยังไม่ใช่โมเดล ตัวบ้านภายนอกใช้โมเดล Kenney ที่มีอยู่ (ถ้าโหลดไม่ได้ใช้กล่องแทน)
- ย่านบ้านแสดงทีละถนน (12 หลัง) ถนนอื่นต้องเลือกผ่าน `?street=` ซึ่ง UI ยังไม่มีปุ่มเปลี่ยนถนน ผู้เล่นทุกถนนอยู่ห้อง realtime โซน HOMES เดียวกัน (shard ตามจำนวนคนเหมือนเดิม) จึงอาจเห็นคนเดินอยู่ทั้งที่อยู่คนละถนน
- ออกจากบ้านแล้วไปเกิดที่จุดเกิดของโซน HOMES ไม่ใช่หน้าประตูบ้าน
- ยังไม่มี: เปลี่ยนพื้น/ผนัง, ขยายบ้าน, กดถูกใจบ้าน, คราฟต์เฟอร์นิเจอร์, ขายบ้าน
- บ้านรับคนพร้อมกันได้ 12 คน (`HOME_FULL`)
